## 💡 Why useai.sh?

Most AI tutorials are shallow Twitter threads or outdated static blog posts. **useai.sh** brings the proven, visual architecture of `roadmap.sh` to the AI era — augmented with **actionable execution drawers**, **customizable prompt sandboxes**, and **real-world production recipes**.

Every node in every roadmap is backed by a structured, 3-tab sliding side drawer:
1. **📘 The Playbook**: A 3-step execution micro-guide (`Setup Context`, `Action & Tool Operation`, `Quality & Lint Checks`), along with recommended model versions, pro-tips, and mistakes to avoid.
2. **🧪 Interactive Prompt Lab**: Production-tested prompt templates with interactive customizable variables (e.g., target stack, schema rules, error handling strategy) and instant one-click copy.
3. **📚 Resources & Concept Guides**: Curated official documentation, step-by-step video deep dives, and architecture specifications.

## ⚡ Key Platform Features

- **🔎 Global Command Palette (`Cmd+K` / `Ctrl+K`)**: Instant fuzzy search across all 38 roadmaps, 330+ steps, 330+ prompt templates, and 180+ tools with keyboard shortcuts (`P`, `T`, `R`, `S`).
- **📑 Actionable 3-Tab Node Drawer**: Deep execution guides that pop open directly from roadmap nodes with `← Prev` and `Next →` navigation, keyboard arrow controls, and automatic scroll-to-top.
- **🔗 Direct URL Deep-Linking**: Share exact nodes or roadmaps with one-click copy buttons (`?roadmap=<id>&step=<nodeId>`).
- **🔖 Local-First Saved Workspace**: Save entire roadmaps, prompts, and tools locally in your browser. Includes a 1-click **JSON Backup & Restore** feature with SHA-256 data validation.
- **📊 Live Progress Tracking**: Track your completion percentage across roadmaps. Roadmap cards dynamically show completion pills (e.g., `4 / 18 Steps` or `100% Done ✓`) and sleek bottom progress bars.
- **🧪 Interactive `/prompts` Directory**: Browse and test 330+ battle-tested prompt templates organized by category and difficulty.
- **🧰 Curated `/tools` Directory**: Explore 180+ developer AI tools with categorizations, pricing models, and direct links.
- **🌓 Dark & Light Modes**: Tailored high-contrast developer theme built with curated HSL design tokens.
- **📱 Fully Mobile Responsive**: Engineered with slide-down hamburger navigation and touch-friendly full-width drawers.

## 🚀 Quickstart

Clone the repository and spin up the local development server in seconds:

```bash
# 1. Clone the repository
git clone https://github.com/useai-sh/useai-sh.git
cd useai-sh

# 2. Install dependencies
npm install

# 3. Start local development server
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser.

### Production Build & Linting

```bash
# Build optimized production bundle
npm run build

# Preview production build locally
npm run preview
```

## 🤝 Contributing

We welcome contributions from developers, AI engineers, and prompt designers!

### Adding or Updating a Roadmap
1. **Metadata**: Add your roadmap entry to `src/data/roadmaps.json` with a unique `id`, `title`, `description`, `category`, and `tools`.
2. **Steps & Phases**: Create a curriculum module in `src/data/roadmaps/<roadmapId>.js` detailing phases, steps, playbooks, prompt templates, and resource links.
3. **Register**: Export your data in `src/data/roadmapSteps.js`.
4. **Test**: Run `npm run build` to verify schema integrity and bundle correctness.
5. **Open a PR**: Submit a pull request with a descriptive title and screenshot/recording.
